MENTOVA UI CONVENTIONS

This file records standing rules for the web pages the Mentova server serves, so that future pages follow them.


BUTTON PRESS RULE

Every button on every page must show an inverted colour scheme while it is being pressed, and must take its action when the mouse button is released.

The exact behaviour is:

• While the mouse button is held down on a button (or a select control), the button's colours invert.

• When the mouse button is released over that button, the colours revert to normal and the button's action fires (this is the normal browser click, which already happens on release).

• If the mouse is dragged off the button while still held down, the button's colours revert and no action fires (again, the normal browser behaviour for a cancelled click).

How it is implemented:

• A single shared script provides this for all buttons on a page: assets/common/press.js

• It is self-contained (it injects its own style), theme-agnostic (it inverts whatever colours a button already has, using a CSS filter), and needs no per-page styling.

• Every served HTML page includes it once, just before the closing body tag:

  <script src="/assets/common/press.js"></script>

Rules for new pages:

• Any new HTML page the server serves MUST include that one line.

• Do NOT re-implement pressed-button styling per page. If the shared behaviour needs to change, change assets/common/press.js in one place.

Pages currently covered:

• assets/arc/arc.html - the ARC-AGI-3 Chat page.

• assets/arc/attempts.html - the ARC-AGI-3 Solo Attempts Record page.

• assets/chat/index.html - the public chat page.

• assets/chat/mentor.html - the Mentor Panel (sign-in, teach, review, and the Mentor Token tool).

• assets/chat/terms.html - the Terms of Use page.
