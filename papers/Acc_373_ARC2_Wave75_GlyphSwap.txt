TASK DESCRIPTION

Task edb79dae presents grids from 22x24 to 30x30. A rectangular frame
of color 5 encloses a display area holding solid square blocks of one
shared size B - 3, 4, and 5 across the three grids - each block painted
in a single color and separated from its neighbors by the display
background. Outside the frame sit two kinds of hints. The first kind is
a set of legend interlocks: 3-row-by-4-column figures built from two
colors A and B in the exact pattern AABB / AAAB / AABB, meaning that
color A maps to color B. The second kind is a set of reference glyphs:
one B-by-B picture per block color, drawn in that color over the
background. In the output only the framed region remains, and every
solid block has been replaced by its color's reference glyph shape,
repainted in the legend-mapped color.

RULE: glyph_swap

The glass-box named rule is a five-stage decoding procedure with no
learned parameters:

1. FRAME DETECTION (arc2_bg_color_/2, hc_bbox4_/5)
   The background is the most common cell value. The frame region is
   the bounding box of all color-5 cells, and all four edges of that
   box must be solid color 5.

2. LEGEND DETECTION (gsw_legends_/8, gsw_legend_at_/10)
   A fixed 12-cell window scans for the interlock pattern AABB / AAAB /
   AABB of two non-background, non-frame colors anchored fully outside
   the frame box. Each match contributes the mapping A to B. The
   collected map must be a function - one target per source color -
   and every covered legend cell is recorded for later subtraction.

3. BLOCK DETECTION (gsw_blocks_/8, bst_components_/2)
   The frame interior is partitioned into same-color 4-connected
   components. Every component must be a solid B-by-B square, which
   fixes the shared block size B.

4. GLYPH EXTRACTION (gsw_glyph_/9)
   For each distinct block color, the reference glyph is the set of
   that color's cells lying outside the frame and outside every legend
   interlock. Its bounding box must be exactly B-by-B, and its cell
   offsets within that box form the glyph mask.

5. RENDER
   The output is the framed subgrid copied cell for cell, except that
   every solid block is replaced by its color's glyph mask repainted
   in the legend-mapped color, with off-mask block cells restored to
   the display background.

THE KEY INSIGHT: SUBTRACT THE LEGENDS BEFORE READING THE GLYPHS

The two hint systems outside the frame share colors. In the test grid
color 9 appears as a legend target (3 maps to 9), as a legend source
(9 maps to 2), and as a reference glyph - three roles for one color in
one grid. Reading the glyph of a color therefore only works after every
legend cell has been subtracted from that color's cell set; what
remains is exactly the B-by-B glyph picture. The second observation is
that no color may be treated as special except the frame color 5 and
the per-grid background: color 8 is the background of one training grid
but a genuine block color in the test grid, arriving via the legend
3 maps to 8 in training and departing via 8 maps to 7 in the test. The
interlock pattern AABB / AAAB / AABB proves distinctive enough for a
single fixed-window scan, because glyphs are single-color over
background and blocks are solid, so the two-color interlock cannot
arise by accident.

INDUCTION PRE-FILTER

The first training pair's output must have strictly fewer rows and
strictly fewer columns than its input, and the first output's top-left
and bottom-left cells must carry the frame color 5. All training pairs
are then verified with forall before the rule is selected. The checks
are constant-time, keeping the pre-filter cheap for every other task in
the named-rule enumeration. The induce clause dispatches early,
directly after hole_census, ahead of the generic named-rule search.

KEY PREDICATES

  gsw_legends_/8       - collect legend interlocks into a color map
  gsw_legend_at_/10    - match one AABB / AAAB / AABB interlock window
  gsw_blocks_/8        - solid B-by-B blocks inside the frame interior
  gsw_glyph_/9         - reference glyph mask after legend subtraction
  bst_components_/2    - same-color 4-connected components (reused)
  hc_bbox4_/5          - cell-set bounding box (reused)
  arc2_bg_color_/2     - most common cell value as background (reused)
  arc2_cell_/4         - bounds-checked cell access (reused)
  arc2_transform(glyph_swap, +Grid, -Out)
  arc2_induce_rule(+Pairs, glyph_swap)
