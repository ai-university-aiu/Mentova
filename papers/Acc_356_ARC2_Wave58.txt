Accomplishment 356: ARC-AGI-2 Wave 58 - Cross Reflect (WP-316, Layer 291)

Author: D. R. Dison, Founder of AIU, Creator and Owner of PrologAI and Mentova, ORCID 0009-0001-9246-5758, linkedin.com/in/d-r-dison/

Date: 2026-07-02

ABSTRACT

Wave 58 adds the cross_reflect rule (WP-316, Layer 291) to PrologAI's ARC-AGI-2
benchmark solver, solving task b10624e5 and raising the score from 54/120 =
45.00% to 55/120 = 45.83%.

The rule recognizes a cross (one complete row and one complete column of a
shared non-background value) that divides the grid into four quadrants. The
top-left quadrant contains a composite shape: an anchor block surrounded by
satellite blocks of other colors. Each other quadrant contains only an anchor
block of the same color but possibly different size. The output adds copies of
the TL satellite pattern to each non-TL quadrant, with the satellites reflected
and scaled to match the anchor block size in each quadrant.


TASK DESCRIPTION

Task ID: b10624e5

Input structure: a 27x27 grid (BG=4) containing a cross of 1s at row 13 and
column 13. The cross divides the grid into four quadrants. The TL quadrant
contains an anchor block of 2s plus satellite blocks of other colors (8, 3, 9,
1 etc.) arranged around the anchor. The TR, BR, and BL quadrants each contain
only an anchor block of 2s, possibly of different size than the TL anchor.

Output structure: same dimensions as input. TL quadrant is unchanged. TR gets
the TL satellite pattern added with left-right reflection and scaled to TR anchor
size. BR gets the pattern with 180-degree rotation and scaled to BR anchor size.
BL gets the pattern with top-bottom reflection and scaled to BL anchor size.


THE CROSS_REFLECT RULE

Step 1 - Locate the cross: arc2_cr_cross_/4 scans rows for the one row where
all cells share a single non-BG value V. Then scans columns for the column where
all cells share the same V. These define cross row R and cross col C.

Step 2 - Find the anchor: arc2_cr_anchor_/5 scans the TR quadrant (rows<R,
cols>C) in row-major order and returns the first non-BG value encountered. This
is the anchor A (color 2 in both training pairs and test case).

Step 3 - Extract satellite information: arc2_cr_bbox_q_/10 finds the TL anchor
bounding box giving top-left (TL_MinR, TL_MinC) and square size N_tl. Then
arc2_cr_sats_/6 finds all distinct non-BG non-anchor values in TL. For each
satellite value SV, arc2_cr_sat_info_/7 computes its bounding box in TL and
returns offset (DR, DC) in cells from TL anchor top-left, plus height SH and
width SW.

Step 4 - Compute target quadrant anchor sizes: find anchor bounding boxes in TR,
BR, and BL quadrants to get (TR_MinR, TR_MinC, N_tr), (BR_MinR, BR_MinC, N_br),
(BL_MinR, BL_MinC, N_bl).

Step 5 - Place transformed satellites: for each satellite (SV, DR, DC, SH, SW),
three transformation functions generate R-C-SV triples:

  TR: arc2_cr_mods_(tr): LR-reflection.
    NewDC = N_tl - DC - SW
    DR_q = DR * N_tr // N_tl
    DC_q = NewDC * N_tr // N_tl
    H_q = SH * N_tr // N_tl
    W_q = SW * N_tr // N_tl
    Place SV block at rows (TR_MinR+DR_q)..(TR_MinR+DR_q+H_q-1),
                     cols (TR_MinC+DC_q)..(TR_MinC+DC_q+W_q-1).

  BR: arc2_cr_mods_(br): 180-degree rotation.
    NewDR = N_tl - DR - SH
    NewDC = N_tl - DC - SW
    Scale and place at BR anchor.

  BL: arc2_cr_mods_(bl): TB-reflection.
    NewDR = N_tl - DR - SH
    DC unchanged
    Scale and place at BL anchor.

Step 6 - Build output: combine all R-C-SV triples into AllMods. Build output
grid using maplist: for each cell, use AllMods value if present, else copy input.

IMPLEMENTATION DETAILS

New predicates (all in arc_benchmark_2.pl, prefixed arc2_cr_):

arc2_cr_cross_/4: between/3 row scan + sort/2 singleton check + non-BG test +
  cut; then between/3 col scan + findall/3 for col values + sort singleton check
  + cut.

arc2_cr_bbox_q_/10: findall Row-Col in quadrant rectangle; split into Rs/Cs lists;
  min_list/max_list for tight bounding box.

arc2_cr_anchor_/5: between row/col scan in TR; first non-BG cell; cut.

arc2_cr_sats_/6: findall non-BG non-anchor in TL; sort deduplicates.

arc2_cr_sat_info_/7: bbox_q_ for satellite in TL; DR=MinR-AR; DC=MinC-AC.

arc2_cr_mods_(tr/br/bl): three separate clauses for LR, 180, TB; each computes
  new_DR/new_DC via reflection formula; scales by N_q//N_tl; findall R-C-SV.

arc2_transform(cross_reflect)/3: cross_ + anchor_ + sats_ + maplist(sat_info_)
  + bbox_q_ x3 + findall(mods_) x3 + append x3 + maplist output.

arc2_induce_rule(cross_reflect): fast-path placed before catch-all; pre-filter
  calls arc2_cr_cross_ on first training input; full forall verification.


KEY INSIGHTS

Scale-factor arithmetic: all satellite offsets and sizes are expressed in
anchor-unit space (1 unit = N_tl cells). When placing in a quadrant with anchor
size N_q, every dimension is multiplied by N_q and integer-divided by N_tl. This
preserves spatial relationships regardless of how large each anchor is.

Reflection symmetry: the four quadrant positions relative to the cross correspond
naturally to the four symmetries of the plane (identity for TL, LR-flip for TR,
180-rotation for BR, TB-flip for BL). The rule exploits these to generate all
three non-TL satellite placements from a single satellite description.

Anchor detection via TR: the anchor is always present as the only non-BG value
in TR. This makes TR the natural quadrant for detecting the anchor without
confusion from the composite TL pattern.


SIGNIFICANCE

cross_reflect demonstrates PrologAI's ability to identify spatial symmetry
groups, extract a composite pattern relative to an anchor element, and apply
scaled reflections of that pattern to multiple target positions simultaneously.
The rule requires: (1) cross detection via single-value row/col scan; (2) anchor
detection via first-non-BG scan in a specific quadrant; (3) per-satellite offset
extraction using bounding boxes; (4) three distinct affine transformations (LR,
180, TB) each with a size-scaling factor determined by the ratio of anchor block
sizes; (5) grid-boundary-safe placement using findall.
