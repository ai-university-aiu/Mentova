Rule Name: layout_tile

Work Package: WP-318

Layer: 293


Pattern Description

The input grid is divided by structural "divider rows" and "divider cols" into
three horizontal row-groups and N vertical col-groups.

A major divider row has all values in {0, 5} AND at least half of its cells
are 5 (the full-width pattern of 5s that spans across all col-groups).

A divider col has all values in {0, 5} AND at least one value is 5.

Row-group 0 (top): contains N template subgrids (one per col-group, size S x S
each, where S is the col-group width and equals the row-group-0 height).

Row-group 2 (bottom): contains N marker cells (one per col-group), each being
the single non-zero non-5 value in that col-group of the bottom row-group.

Row-group 1 (middle): contains N layout subgrids (S x S each). Each non-zero
non-5 cell at position (r, c) in layout L[i] identifies a template T by color
(T is the template subgrid that contains that color). Output block at position
(r, c) in the S x S output arrangement uses template T with all non-zero cells
recolored to T's marker color.

Output: S x S arrangement of S x S blocks = total S^2 x S^2 grid.

Key Implementation Decisions

Divider row detection: The major divider rows span the full grid width with
dense 5 patterns. Sparse-5 rows in the marker region (rows with 5s only at
col-divider positions) must be excluded. The fix: require count(5s) * 2 >= W
using include(==(5), Row, Fives), length(Row,W), length(Fives,NF), NF*2>=W.
Using member(5, Row) in a findall is wrong because member backtracks for each
occurrence of 5, causing duplicate row indices.

Output block membership: Assignments list maps (block_row, block_col) to
template_index. The output builder uses member/2 lookup for each of the S^2
output cells. For S=5, this is 625 lookups, each O(|Assigns|). Performance
is acceptable given small Assigns lists.

Early dispatch: The arc2_induce_rule(layout_tile) clause is placed before
the generic arc2_induce_rule(Pairs, Rule) clause. This ensures the fast
structural pre-filter (two identical major divider rows) is tested without
going through 60+ named rules in the generic clause first.


Prolog Implementation

% arc2_lt_solve_(+Grid, -Out): main layout_tile solver.
arc2_lt_solve_(Grid, Out) :-
% Find all divider rows (rows with only 0/5 values).
    arc2_lt_divider_rows_(Grid, DivRows),
% Find all divider cols (cols with only 0/5 values, at least one 5).
    arc2_lt_divider_cols_(Grid, DivCols),
% Split into 3 row-groups: template (top), layout (middle), marker (bottom).
    arc2_lt_row_groups_(Grid, DivRows, RG0, RG1, RG2),
% Split into N col-groups (non-divider, non-padding groups).
    arc2_lt_col_groups_(Grid, DivCols, ColGroups),
% S = width of each col-group = block size.
    ColGroups = [G0|_], length(G0, NS),
% Extract template, marker, and layout subgrids.
    arc2_lt_subgrids_(Grid, RG0, ColGroups, Templates),
    arc2_lt_markers_(Grid, RG2, ColGroups, Markers),
    arc2_lt_layouts_(Grid, RG1, ColGroups, Layouts),
% Compute assignments: (br,bc,template_index) for each layout cell.
    arc2_lt_assignments_(Layouts, Templates, Assigns),
% Build the S*S x S*S output grid.
    arc2_lt_build_output_(Assigns, Templates, Markers, NS, Out).

% arc2_lt_divider_rows_(+Grid, -DivRows): rows with all values in {0,5}, >=half are 5.
arc2_lt_divider_rows_(Grid, DivRows) :-
% A major divider row spans the full grid width with 5s; at least half the cells are 5.
    findall(R,
        (nth0(R, Grid, Row),
         \+ (member(V, Row), V \= 0, V \= 5),
         include(==(5), Row, Fives),
         length(Row, W), length(Fives, NF),
         NF * 2 >= W),
        DivRows).
