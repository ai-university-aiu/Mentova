TASK DESCRIPTION

Task 58f5dbd5 presents three training pairs and one test case. The
inputs are 19x19, 19x19, 23x18, and 23x18; the outputs are 19x7,
7x19, 13x13, and 19x13. Every input holds several solid five-by-five
monochrome square blocks standing in a regular grid arrangement with
one-cell background gaps - one column of three blocks, one row of
three blocks, a two-by-two arrangement, and a three-by-two
arrangement across the four grids - each block a distinct
non-background color. Elsewhere in the scene lie small three-by-three
sketch motifs of various colors, including decoy sketches whose
colors have no matching block. The output keeps the block arrangement
on a fresh background canvas, and each block's central three-by-three
region is carved with the negative of its same-colored sketch:
wherever the sketch shows the block color, the output cell turns
background; wherever the sketch shows background, the cell keeps the
block color.

RULE: stencil_carve

The glass-box rule is a four-stage procedure whose parameters are
all read off the input grid at solve time:

1. BLOCK DETECTION (stc_block_/5)
   The background is the most common color of the scene. The scan
   finds every solid five-by-five square of one non-background
   color, anchored at a top-left corner whose upper and left
   neighbors differ from the block color, so larger regions cannot
   yield duplicate placements.

2. ARRANGEMENT RECOVERY
   The distinct block starting rows and starting columns define a
   complete row-by-column arrangement; the block count must equal
   the product of the row count and the column count.

3. SKETCH COLLECTION (stc_sketch_/4, stc_in_block_/3)
   For each block color, every cell of that color outside all
   blocks is collected, and the bounding box of the collection
   must be exactly three by three. The sketches may be
   8-disconnected within their bounding boxes, so bounding-box
   collection is more robust than connected-component analysis.
   Sketch colors without a matching block are decoys and are never
   visited.

4. CANVAS RENDERING (stc_tile_/4, stc_tcell_/6, stc_cell_/5)
   The output canvas has height six times the block rows plus one
   and width six times the block columns plus one, all background.
   Each block is stamped as a solid five-by-five square in its
   color at position (1 + 6i, 1 + 6j), and its central
   three-by-three region is carved: a sketch cell of the block
   color punches the output cell down to background, and a sketch
   background cell leaves the block color standing.

KEY INSIGHT

The carving inversion is the discriminating observation of the
wave. The block interior is not a copy of the sketch but its
punched-out negative - the sketch acts as a stencil whose colored
cells are the holes. A second observation is that the output shape
is not fixed: the four grids exercise four different block
arrangements, so the output dimensions follow the arrangement
recovered from the input rather than any constant frame. The test
grid presents the largest arrangement, three block rows by two
block columns of colors 4, 8, 2, 1, 6, and 9, carved from six
sketches scattered in the left third of the scene.

INDUCTION AND VERIFICATION

The rule has no learned parameters. The background, the blocks,
the arrangement, and the sketches are all read off the input grid
at answer time. Induction is pure verification: a cheap pre-filter
(output height and width both one more than a multiple of six, and
a background top-left output corner) followed by transformation of
every training pair. The Python prototype passed all three
training pairs and the test case on the first run, and the
integrated Prolog rule passed the single-task test and the full
regression of all 88 locally verified tasks on the first compile.
