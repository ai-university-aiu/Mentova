ACCOMPLISHMENT

Wave 67 of the ARC-AGI-2 benchmark climb: task 0934a4d8 solved using the
mirror_patch rule (WP-325, Layer 300). Score advances from 63/120 = 52.50%
to 64/120 = 53.33%.

TASK DESCRIPTION

Task 0934a4d8 presents 30x30 grids showing a mirror-symmetric wallpaper in
which one rectangular patch has been covered by a solid block of color 8.
The output is not the healed grid: it is the recovered hidden patch alone,
exactly the height and width of the covered rectangle, containing no 8s.
The four training covers range from 3x7 to 9x4 cells and sit in different
parts of the grid; the test cover is a 9x3 block flush against the left
edge, the hardest placement for mirror-based recovery.

RULE: mirror_patch

The glass-box named rule is a four-stage deterministic recovery with no
learned parameters:

1. SOLID COVER LOCATION (mp_bbox8_/5)
   Collect every color 8 cell and compute its bounding box. The block is
   accepted only when the cell count exactly fills the bounding box, so
   stray 8s elsewhere in a grid reject the rule immediately.

2. MIRROR AXIS DETECTION (mp_axis_/5)
   The wallpaper's horizontal mirror axis is a column reflection sum SC
   with G[r][c] = G[r][SC-c]; the vertical axis is a row reflection sum SR
   with G[r][c] = G[SR-r][c]. Each candidate sum is tested against every
   pair of visible (non-8) cells it relates: one disagreement rejects the
   candidate, and more than 50 supporting pairs are required. In all five
   grids of this task the detected sum is 31 (axis between rows/columns 15
   and 16), NOT the grid-center sum 29. The 30x30 grid is an asymmetric
   crop of the wallpaper: rows and columns 0 and 1 have no in-grid mirror
   partners. Hard-coding the grid-center mirror fails every pair, which is
   why the axis must be detected from the data.

3. MIRROR FIXPOINT HEALING (mp_mirror_pass_/6)
   Every covered cell takes the value of its horizontal mirror (r, SC-c),
   vertical mirror (SR-r, c), or point mirror (SR-r, SC-c), whichever is
   visible first. Healed cells become donors for later iterations, so the
   pass repeats until no covered cell can be filled.

4. TRANSPOSE FALLBACK (mp_transpose_pass_/5)
   The test cover hugs the left edge: columns 0-1 mirror to columns 30-31
   (outside the grid) and rows 14-17 mirror to rows 17-14 (inside the
   cover itself), so eight cells are unreachable by any mirror. These fall
   back to the transpose donor (r, c) <- (c, r), which holds exactly in
   the central band of the wallpaper; the mirror fixpoint then runs again
   and completes the patch. The transform succeeds only if the extracted
   patch is free of 8s.

INDUCTION PRE-FILTER

The first training input must contain a solid rectangle of 8s whose
bounding-box height and width equal the output dimensions, and the output
must contain no 8; all training pairs are then verified with forall before
the rule is selected.

WHY AXIS DETECTION MATTERS

A wallpaper crop need not be centered on a symmetry axis. Detecting the
reflection sum from visible cells with a zero-conflict test plus a support
threshold finds the true axis uniquely in all five grids and generalizes to
any crop offset, whereas any fixed axis assumption is brittle. The same
zero-conflict discipline that made mosaic_heal (Wave 66) converge is reused
here at the level of whole symmetry axes rather than donor rows.

KEY PREDICATES

  mp_bbox8_/5          - solid color 8 cover rectangle location
  mp_axis_/5           - conflict-free mirror axis detection with support
  mp_heal_/6           - mirror fixpoint, transpose fallback, iterate
  mp_mirror_pass_/6    - fill covered cells from H, V, or point mirrors
  mp_transpose_pass_/5 - fill covered cells from transpose donors
  arc2_transform(mirror_patch, +Grid, -Out)
  arc2_induce_rule(+Pairs, mirror_patch)

VERIFICATION

All 4 training pairs and the test case pass in SWI-Prolog. A full
benchmark regression run confirms no previously solved task lost its rule.
Pure induction from training examples. No pretraining on the ARC-AGI-2
corpus. Every rule is named and glass-box.
