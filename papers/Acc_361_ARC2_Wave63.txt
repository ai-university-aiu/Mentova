Pattern Description

The input grid contains vertical column segments and indicator bars. Each
column segment has the pattern [M, F, F, ..., F, M] (marker color M at top
and bottom, filler color F filling the middle). Indicator bars appear at the
top of certain columns: if a column has a non-background color at row 0, the
length of that color's consecutive run from row 0 downward gives a rank.

The key rule: for each indicator (marker_color M, rank R), collect all
column segments whose top and bottom markers have color M. Sort these
segments by filler-cell count in descending order. Select the segment at
rank R (1-indexed). Replace all filler cells in that selected segment with
the marker color M (making the segment a solid block of M).

Indicator bars and column segments can coexist in the same column at
different row ranges. The indicator bar detection always starts at row 0;
segment detection skips the bar rows.

Key Implementation Decisions

Indicator bar length as rank: the bar for a given color counts how many
consecutive rows from the top of the grid share that color. This number
directly becomes the rank (1-indexed position) in the descending-sorted
list of segments for that marker color.

Same-column indicator and segment: a column can have an indicator bar
(rows 0..L-1) and a segment (rows L..H-1) at the same time. The segment
detection starts at row L (BarLen), skipping the indicator bar section.
This happens in pair 3 col 2 (bar color 3 at rows 0-1, segment marker 1
at rows 4-9) and test col 1 (bar color 2 at row 0, segment marker 2 at
rows 4-9).

Out-of-range rank: if the rank from an indicator bar exceeds the number
of segments with that marker color, no change is applied for that color.
This handles pair 3's col 2 bar (color 3, rank 2) and the test's col 2
bar (color 3, rank 3 with only 2 segments).

Filler validation: the arc2_crf_seg_ predicate verifies that all
intermediate cells (between the two markers) have the same non-BG,
non-marker color. This prevents spurious segment detection.

Replacement: all cells from TopRow to BotRow (inclusive) in the target
column are replaced with the marker color. Since the top and bottom are
already the marker, only the filler cells change visually.


Prolog Implementation (key predicates)

% arc2_crf_indicators_: find indicator bars (col, color, bar_length).
arc2_crf_indicators_(Grid, W, Indicators) :-
    W1 is W - 1,
    findall(C-Color-Len, (
        between(0, W1, C),
        nth0(0, Grid, R0), nth0(C, R0, Color), Color =\= 0,
        arc2_crf_bar_len_(Grid, C, Color, 0, 0, Len)
    ), Indicators).

% arc2_crf_targets_: for each indicator, select rank-R segment descending.
arc2_crf_targets_(Indicators, Segs, Targets) :-
    findall(Col-Marker-TR-BR, (
        member(_-Marker-Rank, Indicators),
        findall(N-C-TR-BR, member(C-Marker-N-TR-BR, Segs), MSegs0),
        MSegs0 \= [],
        msort(MSegs0, Sorted0), reverse(Sorted0, Sorted),
        nth1(Rank, Sorted, _-Col-TR-BR)
    ), Targets).
