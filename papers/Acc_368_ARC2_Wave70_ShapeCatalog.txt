TASK DESCRIPTION

Task 67e490f4 presents 30x30 grids dominated by one large lattice block
built from exactly two colors: a frame color (for example color 4) drawn
over the background color (for example color 1). The lattice encloses
small pockets of background cells - 2x2 squares, dominoes, pluses,
L-triominoes, bars, and larger glyphs. The field outside the block is
scattered with small monochrome shapes, each drawn in its own color: a
shape catalogue. The output is the block alone, cropped along its bounding
box, with every background pocket recolored to the color of the
same-shaped catalogue entry. The two training blocks are 11x11 and 13x13;
the hidden test block is a 7x30 band spanning the full grid width.

RULE: shape_catalog

The glass-box named rule is a four-stage catalogue-lookup procedure with
no learned parameters:

1. BLOCK DETECTION (arc2_bg_color_/2, arc2_all_comps_/3, scg_largest_/2)
   The background is the most frequent cell value. All non-background
   cells are partitioned into 4-connected same-color components, and the
   component with the most cells is the frame lattice. Every cell inside
   the lattice's bounding box must be frame color or background - the
   two-color block guard - and the block is cropped along that box
   (scg_bbox_/5, scg_crop_/6).

2. CATALOGUE CANONICALIZATION (scg_canon_/2, scg_norm_/2, scg_d4_/5)
   Every non-frame component is a catalogue entry. Its cells are shifted
   so the minimum corner sits at the origin, the eight dihedral-four
   variants (identity, two flips, half turn, transpose, both quarter
   turns, anti-transpose) are generated by the eight scg_d4c_/6 coordinate
   maps, and the lexicographically smallest variant becomes the canonical
   shape, paired with the entry's color.

3. MOTIF EXTRACTION (arc2_all_comps_/3 reused on the crop)
   The background pockets inside the block are recovered by rerunning the
   standard component sweep over the cropped block with the frame color
   passed as the background argument - the pockets emerge as 4-connected
   motif components with no dedicated pocket-walking code.

4. DOMINANT VOTE AND PAINT (scg_assign_/3, scg_dominant_/2, scg_paint_/4)
   Each motif is canonicalized the same way and collects the colors of
   every catalogue entry with an identical canonical shape. At least one
   vote is required; the most frequent color wins, with the smallest color
   value breaking ties. The block is rebuilt cell by cell: frame cells
   stay frame colored, and each motif cell takes its assigned color.

THE KEY INSIGHT: MATCH SHAPES UP TO ROTATION AND REFLECTION, THEN VOTE

Two design decisions carry the rule. First, matching must be invariant
under the dihedral-four group: the test block holds a horizontal domino
whose only catalogue mates are drawn vertically, and the block corners
repeat one L-triomino in four orientations while the catalogue draws it
in fewer - raw normalized cell-set matching fails, canonical
dihedral-four matching resolves every motif. Second, the assignment is a
vote, not a first match: in training pair 1 the 2x2 square motif matches
catalogue squares of colors 8, 2, and 3 at the same time, and the correct
output paints it with color 8, the color holding the most catalogue
entries. A pleasant structural bonus: the two-color bounding-box guard
already guarantees that every other component stands outside the block,
so the catalogue is simply every non-frame component with no positional
filtering at all.

INDUCTION PRE-FILTER

The first training pair must have an output that fits inside its input
and is strictly smaller in at least one dimension (the crop shrinks), and
the first input must carry at least five distinct colors (frame,
background, and at least three catalogue colors); all training pairs are
then verified with forall before the rule is selected. Inside the
transform, the two-color block guard fails fast on grids whose largest
component box holds foreign colors, keeping the rule cheap for every
other task in the named-rule enumeration.

KEY PREDICATES

  scg_largest_/2   - component with the most cells (the frame lattice)
  scg_bbox_/5      - bounding box of a cell list
  scg_crop_/6      - cut the bounding-box subgrid out of the input
  scg_canon_/2     - canonical shape under the eight dihedral-four maps
  scg_norm_/2      - shift cells so the minimum corner is the origin
  scg_d4_/5        - apply one dihedral-four transform to a shape
  scg_d4c_/6       - the eight per-cell coordinate maps
  scg_assign_/3    - motif to catalogue-color assignment by canonical shape
  scg_dominant_/2  - most frequent vote, smallest color value on ties
  scg_paint_/4     - rebuild the recolored block
  arc2_transform(shape_catalog, +Grid, -Out)
  arc2_induce_rule(+Pairs, shape_catalog)
