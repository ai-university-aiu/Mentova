ABSTRACT

Wave 59 adds the scaled_frame rule (WP-317, Layer 292) to PrologAI's ARC-AGI-2
benchmark solver, solving task 898e7135 and raising the score from 55/120 =
45.83% to 56/120 = 46.67%.

The rule recognizes a rectangular frame (a solid-colored border with 0-hole cells
inside) in the input grid, along with colored object-blobs placed outside the
frame in the background. The scale factor N is derived as sqrt(GCD of all object
cell-counts). The output is the frame scaled by N, with each 0-hole region in the
frame filled by the color of its matched background object. Matching uses a
(normalized_size, centroid_column) sort-pair order to resolve ties.

THE SCALED_FRAME RULE

Step 1 - Locate the frame:
arc2_sf_frame_/6 iterates over each distinct non-background color FC. For each
FC, it collects all cells of that color, computes their bounding box (R0,C0,R1,C1),
and calls arc2_sf_solid_border_/6 to verify that all four border edges (top row
R0, bottom row R1, left column C0, right column C1) are completely filled with FC.
Then it checks that at least one 0-cell exists strictly inside the bounding box
interior. The first color passing all tests is the frame color.

Step 2 - Extract hole components:
arc2_sf_holes_/6 collects all 0-cells in the frame interior (rows R0+1..R1-1,
cols C0+1..C1-1). arc2_sf_conn_comps_/2 finds the 4-connected components of those
0-cells using BFS (arc2_sf_comps_/2 and arc2_sf_bfs_/5). Each component is a
hole-group.

Step 3 - Identify background objects:
arc2_sf_objects_/7 collects all non-background non-FC cells that lie outside the
frame bounding box. It finds their 4-connected components (using the same BFS
predicates) and discards any component with fewer than 4 cells (noise filter).
Each surviving component is recorded as (color, cell-list).

Step 4 - Compute scale factor:
arc2_sf_scale_/2 collects the cell-counts of all background objects. arc2_sf_gcd_list_/2
folds GCD across the list of counts using SWI-Prolog's built-in gcd/2. The scale
factor is round(sqrt(float(G))) where G is the GCD.

Step 5 - Match hole-groups to object colors:
arc2_sf_match_/4 annotates each hole-group as a triple (size, centroid_col, HComp)
and each object as (size // Scale^2, centroid_col, Color). arc2_sf_centcol_/2
computes centroid column as the mean column coordinate of all cells. msort/2 sorts
both annotated lists by (size, centroid_col) in ascending order. arc2_sf_pair_match_/3
pairs the N-th hole-group annotation with the N-th object annotation, extracting
the HComp and Color. This sort-pair strategy ensures that among objects of equal
normalized size, the one with the smaller centroid column fills the hole-group
with the smaller centroid column.

Step 6 - Build the output grid:
arc2_sf_solve_/2 computes OutH = (R1-R0+1)*Scale and OutW = (C1-C0+1)*Scale.
It builds the output by maplist over all output rows and columns. For each
output cell (R,C), arc2_sf_cell_val_/8 computes the frame cell position:
FRow = R0 + R // Scale, FCol = C0 + C // Scale. It reads the value at (FRow,FCol)
in the original grid. If that value is 0 (a hole), arc2_sf_hole_color_/4 looks up
the fill color from Matches by finding which hole-group contains (FRow, FCol).
Otherwise the output value is FC.


KEY INSIGHTS

Frame identification - The solid-border test (all four edges solid FC) uniquely
selects the frame color from among all non-background colors. Interior cells may
be either FC (interior walls) or 0 (holes); both are valid. Background object blobs
and noise cells fail the test because their bounding box borders contain cells of
other values.

Scale from GCD - Each background object corresponds to exactly one hole-group:
if the hole-group has H cells and the scale is N, the object has H * N^2 cells.
Therefore GCD of all object cell-counts = N^2, so N = sqrt(GCD). Computing via
round(sqrt(float(GCD))) avoids integer square root truncation errors.

Tie-breaking by column - When multiple hole-groups have the same size and multiple
objects share the same normalized size, sorting both by centroid column and pairing
in order places left-side hole-groups with left-side objects. This spatial locality
invariant is satisfied by every training pair and the test case.

Output by integer division - Output cell (R,C) maps to frame cell
(R0 + R//N, C0 + C//N). This uniformly tiles the frame N times in each dimension:
the N consecutive output positions mapping to the same frame row/col all receive
the same value, producing perfect N*N blocks for every frame cell.

Noise filter - Objects with fewer than 4 cells (isolated noise markers) are
excluded before GCD computation and before matching. This prevents noise cells
from affecting the scale factor or consuming hole-group matches.
