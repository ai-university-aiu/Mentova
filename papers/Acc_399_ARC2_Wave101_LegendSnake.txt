TASK DESCRIPTION

Task 195c6913 presents three training pairs and one test case. The
grids range from 20x20 to 30x30; the output always keeps the input
size. Each input shows two large regions of two dominant colors
meeting along a jagged diagonal boundary, with stray cells of each
color scattered inside the other region. Near the top-left corner a
legend strip of two-by-two blocks, separated by single background
columns, spells out a color sequence - three blocks reading 2, 2, 8
in the first pair, two blocks reading 4, 1 in the second, three
blocks reading 2, 2, 3 in the third, and four blocks reading
1, 2, 8, 3 in the test. Elsewhere a lone two-by-two block of one
extra color - 4, 9, 8, and 6 across the four grids - names the turn
color. Single marker cells of the legend's first color sit on the
left edge inside one of the two regions. In the output each marker
has fired a snake path eastward through its own region, painted with
the legend pattern repeating cyclically; every time the path ran
into the other region, the blocking cell took the turn color and the
snake pivoted north, then east again at the next block, climbing the
diagonal boundary like a staircase; and both the legend strip and
the lone turn block have been erased to the region color around
them.

Two properties make the task hard. First, the paint program and the
navigation are interleaved: the cyclic pattern must flow unbroken
around every corner, so the turn marks must consume no pattern
position. Second, the path's ending must be read correctly from the
scene: a snake stops silently at the grid edge, but a snake whose
pivot direction is also blocked stops after painting exactly one
turn mark - the second training pair's lower snake dies against the
boundary this way after a single mark.

RULE: legend_snake

The glass-box rule is a five-stage procedure whose parameters are
all read off the input grid at solve time:

1. REGION READING (ls_region_colors_/3)
   The two region colors are the two most frequent colors of the
   grid.

2. LEGEND AND TURN BLOCK (ls_blocks_/4, ls_legend_/4)
   Every two-by-two block of a non-region color is collected. The
   blocks sharing one top row form the legend strip, read left to
   right as the repeating pattern; the single remaining block names
   the turn color.

3. MARKERS (ls_markers_/3)
   The markers are the left-edge cells carrying the pattern's first
   color; each marker's region color is read from the cell directly
   beside it.

4. ERASURE (ls_erase_/6, ls_fill_color_/6)
   The legend strip and the lone turn block are erased to the
   region color found orthogonally next to them.

5. SNAKE WALK (ls_path_/7, ls_walk_/12, ls_step_/15, ls_turn_/4)
   Each snake starts at its marker as pattern position zero and
   walks east through its own region, painting the pattern
   cyclically. A cell outside the region blocks the snake: the
   blocking cell is painted the turn color, no pattern position is
   spent, and the heading pivots from east to north or from north
   to east, resuming from the last path cell. If the pivoted
   direction is also blocked the path ends without a second mark,
   and walking off the grid edge ends the path silently. The snake
   reads region membership from the untouched input grid while
   painting onto the working copy.

The discriminating observation is the pivot bookkeeping. The turn
mark spends no pattern position, so the cyclic pattern flows
unbroken around every staircase corner - verified position by
position across all six snakes of the four grids - and the second
training pair's lower snake, whose pivot direction is blocked
immediately, proves that a blocked pivot ends the path after
exactly one turn mark, quietly.
