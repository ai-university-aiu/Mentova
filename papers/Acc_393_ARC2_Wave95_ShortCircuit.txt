TASK DESCRIPTION

Task 7b0280bc presents three training pairs and one test case. The
grids are 18x18, 15x15, and 20x20 in training and 30x30 in the
test; the output always keeps the input size. Each scene draws a
wiring network on a uniform background using exactly three
foreground colors. One color forms exactly two blocks - the
terminals of a circuit. A second color forms small rectangular
junction blocks scattered through the network. The third color
forms the wire segments that run between junctions and terminals,
bending, running diagonally, and branching. The output recolors
exactly one route through this network - the route with the fewest
nodes between the two terminals - and leaves everything else,
including the terminals themselves, untouched.

Two properties make the task hard. First, the colors permute
freely across pairs: the color that serves as wire body in one
pair serves as junction marker in another, so the roles must be
derived from each grid at solve time, never memorized. Second,
the network is a genuine graph, not a pair of disjoint routes:
junction blocks carry three or more attached segments, dead-end
spurs hang directly off the terminals, and in the test grid one
junction block serves both the shortest route and a long
alternative - so the route must be found by graph search.

RULE: short_circuit

The glass-box rule is a five-stage procedure whose parameters are
all read off the input grid at solve time:

1. ROLE RECOGNITION (scc_palette_/5, scc_runs_/2)
   The most common color is the background. The exactly three
   foreground colors are ranked by ascending cell count: the
   rarest is the terminal color, the middle one is the junction
   marker color, and the most frequent is the wire body color.

2. COMPONENT INVENTORY (sw_parts_/5, scc_fgcells_/3, scc_tag_/3)
   All foreground cells are grouped into whole same-color
   components under eight-way adjacency, reusing the Wave 94
   component machinery verbatim. The terminal color must form
   exactly two components - the two terminals of the circuit.

3. GRAPH CONSTRUCTION (scc_index_/2, scc_adj_/3, scc_neigh_/4)
   Every component is a node. Two nodes share an edge when any
   cell of one is eight-adjacent to any cell of the other.

4. ROUTE SEARCH (scc_bfs_/5)
   A breadth-first search from one terminal to the other yields
   the route with the fewest nodes.

5. RECOLORING (scc_recolor_/5, scc_paint_/4)
   Every intermediate node of that route is recolored: wire body
   components turn 5 and junction marker components turn 3. The
   terminals, the dead-end branches, and every longer alternative
   route stay exactly as they were.

The discriminating observation is that route selection is a
fewest-node graph search. The network cannot be split into two
candidate routes and compared, because the junction blocks are
shared: one marker block in the test grid sits on both the
shortest route and a long alternative, and dead-end spurs hang
off the terminals themselves. Counting nodes is the right metric:
in every pair the recolored route is the unique fewest-node path
between the two terminals, and no cell-count or Euclidean
tie-break was needed.
